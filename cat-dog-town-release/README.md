# Paw Town · 猫狗小镇

给共用一部 iPad 的两位初学英语的孩子设计的冒险网页。各自养一只从幼崽逐渐长大的猫或狗，也会一起点亮小镇。课程从实物、中文意思和英语单词开始，再进入听指令、找物品、图词配对、拖动搭建和开口说话。故事里不会在教会 `cat` 之前直接要求孩子理解 `Find the cat`。

网页提供七集主线和画画、搭建、玩球、寻宝、九个家人小场景。每天 20 分钟是设计目标，没有强制倒计时。真实时长与难度还需两个孩子在 iPad 上试玩后调整。

## 在 iPad 上玩

1. 用 Safari 打开发布网址，建议横屏。先选自己的档案和宠物。
2. 每集先点图卡认识新词，再听英语、找物品、完成互动；点英文、中文或拼音可听对应发音。英文示范可在关卡内切换美式或英式。
3. 口语关卡点麦克风。识别不顺利时可多听几遍；三次未识别会温和地放到下次复习，不给分数或排名。
4. 家长进入“学习记录”，可试听普通话音色，为每集及每位家人的开场录制自己的中文旁白，并定期导出备份。录音只留在当前浏览器的 IndexedDB，备份文件不含录音。

浏览器合成语音的音色取决于 iPadOS。项目已让中文以正常语速播放，家长可试听选择可用音色；希望有真正讲故事的语气，建议在 iPad 上录一遍家人的声音。语音识别与录音必须在实际 iPad Safari 试用，麦克风权限、系统版本和网络都会影响结果。清除 Safari 网站数据会清除没有备份的进度和录音。

## 私人家庭资料

真实姓名和生活故事应保存在项目目录之外的私人家庭资料包中。在孩子使用的 iPad 上，家长页点“导入家庭故事”选这个 JSON 文件；如果选文件没有打开，也可展开“粘贴家庭资料”并粘贴 JSON。导入只更新姓名和故事，不覆盖学习进度。网页源码只保留通用场景，不包含家人的真实姓名。不要把私人资料包或备份上传公开仓库。

资料只保存在该设备 Safari。若换设备，先从旧设备导出备份，再在新设备导入；家长录音目前需要重新录制。

## 本地预览与检查

项目没有运行时依赖。在项目目录运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。逻辑检查命令：`node --test tests/*.test.mjs`。

## GitHub Pages 发布

将发布包解压后把文件放入公开仓库根目录，或上传 `index.html`、`styles.css`、`src/`、`assets/`、`.nojekyll`。在仓库 **Settings → Pages** 选择 **Deploy from a branch**、主分支和 **/(root)**。部署完成后，要用实际 Pages 网址检查图片、课程、家长页及 iPad Safari 语音。网站本身不需要服务器、付费 API、账号或数据库。
